# 여러 샷에 색상을 일치시킵니다. 색상 휠이 필요하지 않습니다.

Premiere Pro의 [색상] 모드를 사용하여 같은 편집에 속한 것처럼 다르게 조명을 비추는 방법에 대해 알아봅니다. 컷에서 컷까지 편집의 일관성이 느껴지도록 샷 하나의 균형을 맞추고, 해당 등급을 유사한 클립에 복사하고, 풀의 파란색과 같은 특정 색상을 미세 조정하는 방법을 살펴보세요.
