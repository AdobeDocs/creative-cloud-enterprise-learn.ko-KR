# 스케치에서 깔끔하고 편집 가능한 벡터

모든 모양을 일일이 손으로 구축하지 않고 Illustrator에서 러프 스케치를 편집 가능한 벡터 아트워크로 변환하는 방법에 대해 알아봅니다. 개념에서 벡터 로 산 스케치를 해석하는 방법, 직접 선택 툴로 결과를 정리하는 방법, 생성형 색상 변경 툴을 사용하여 디자인을 완벽하게 제어하면서 야외 광고 캠페인의 색상 옵션을 살펴보세요.
