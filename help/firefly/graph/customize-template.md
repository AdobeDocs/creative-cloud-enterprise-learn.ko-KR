# &#x200B;6. 템플릿 맞춤화

모든 템플릿은 샘플 입력 및 일반적인 사용 사례와 함께 제공됩니다. 사용자의 간략한 정보, 에셋 및 결과를 반영해야 *사용자*&#x200B;에게 작동하는 워크플로가 됩니다.

1. **샘플 입력을 나만의 에셋 또는 간략히 바꿉니다.**
2. **자리 표시자 텍스트를 계속 사용하는 노드 또는 레이블의 이름을 바꿉니다.**
3. **결과를 신뢰하기 전에 그래프를 한 번, 완전히 실행하십시오.**
4. **변수 하나를 변경하고 다시 실행**&#x200B;하면 해당 단계의 컨트롤을 정확하게 확인할 수 있습니다.
5. **사용자 지정 버전을 고유한 이름으로 저장합니다.**

[Firefly Graph 시작하기](https://experienceleague.adobe.com/en/docs/creative-cloud-enterprise-learn/cce-learning-hub/fireflyoverview/firefly-graph/overview-firefly-graph)&#x200B;(으)로 돌아갑니다.
